# UD Mathematics Events

Quarto website for recurring events hosted by the University of Dayton Department of Mathematics.

## Important rendering note

Do **not** render only `index.qmd` if you want the navigation tabs to work.

Render the entire website project:

```bash
quarto render
```

or use **Render Website** / **Preview Website** in RStudio.

The rendered site is written to the `docs/` folder so it can be published with GitHub Pages.
